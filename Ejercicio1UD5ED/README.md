# Proyecto Javadoc - Pablo Manuel Fernández Velázquez

## Descripción
Aplicación desarrollada en Java para practicar la documentación del código mediante Javadoc.

## Características
- Documentación Javadoc completa
- Clases e interfaces documentadas
- Métodos con parámetros y valores de retorno explicados

## Requisitos
- Mínimo JDK 8.
- USADO (NetBeans IDE 28)

## Instalación
1. Abrir el proyecto en NetBeans.
2. Compilar el proyecto.
3. Ejecutar la aplicación.

## Generación de Javadoc
Click derecho sobre el proyecto → Generate Javadoc.
